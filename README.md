# Lies_detector
This project explores the potential of detecting deception based on facial microexpressions using neural networks and computer vision techniques.
Use predict(video_path) function in Lie_detection.ipynb to see if the person speaking on the video is truthful or deceptive.

Used technologies:
- Python
- PyTorch
- Scikit-Learn
- OpenCV
- NumPy
- gdown

  Best achieved accuracy: 75.68%.
